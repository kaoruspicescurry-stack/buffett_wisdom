# buffett_wisdom — バフェット投資節約術 YouTube企画構成案

このリポジトリは、投資の神様ウォーレン・バフェットの投資哲学、倹約の知恵、そして昨今のキャッシュ積み増し（米国株売却）に対する視聴者分析と、それを基にした高視聴維持率YouTube動画の構成案を自動生成したプロジェクトです。

## 📁 ディレクトリ構成

- `README.md`: 本ファイルの概要と説明
- `buffett_wisdom_構成案.md`: ターゲット視聴者向けの構成案（タイトル・サムネイル・パート別設計）
- `③_視聴者インサイト分析.md`: 抽出した5つの視聴者心理クラスターと示唆
- `④_動画の逆解析.md`: 参考動画5本の展開パターン、フック、離脱防止の仕掛け分析
- `comments_raw.md`: 分析対象となったYouTubeコメント生データ（約650件）
- `fetch_data.py`: コメント取得および字幕クレンジング用の自動化スクリプト
- `buffett_wisdom_pipeline_report.md`: コンテンツパイプラインの全工程実行レポート

## ⚙️ パイプライン実行プロセス

1. **Stage 1 & 2**: `yt-dlp`による自動字幕抽出と、YouTube Data APIによるコメントデータのスクレイピング・クレンジング。
2. **Stage 3**: コメントテキストを横断分析し、視聴者が現在抱えている「円安への不安」「機会損失の焦り」「見栄消費への疲れ」といった本音をクラスター化。
3. **Stage 4**: 参考動画が視聴者を引きつけて離さないための「仕掛け（比喩表現、ストーリーテリング、感情の落とし）」を分解・抽出。
4. **Stage 5**: インサイト（③）と技法（④）をマッピングし、感情曲線を加味したパート別構成案を一発生成。
